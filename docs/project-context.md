# Ghost Cart project context

Ghost Cart is a UAE-first, simulation-only product for impulse purchases and abandoned carts. Users place tempting products into a simulated cart, complete a Fake Checkout, receive a Ghost Receipt, and record the closure of an almost-buy without making a real payment.

Primary line: **Add to cart. Checkout. Keep your money.**

Positioning: **The fake checkout app for everything you almost bought.**

Core loop: craving → Ghost Cart → Fake Checkout → Ghost Receipt → reflection → control.

The first release is a free marketing website and interactive browser demo. It does not process payments, place orders, deliver products, store money, or operate as a bank/payment service.
