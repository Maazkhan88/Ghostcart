# Ghost Cart project instructions

- Treat `docs/project-context.md`, `docs/brand-guidelines.md`, and `docs/product-spec.md` as the product source of truth.
- Ghost Cart is simulation-only. Never add real payments, real delivery, banking claims, card details, payment-network logos, or proof-of-purchase language.
- Use the supplied official logo and UAE Dirham symbol when they are added to `public/brand/`. Do not redraw or approximate them.
- Keep the visual system primarily black, white, and soft gray. Use `#64D64A` sparingly for positive action and control.
- Prefer semantic HTML, keyboard-accessible controls, visible focus states, touch alternatives, reduced-motion support, and responsive layouts.
- Do not invent user counts, savings totals, testimonials, partner brands, ratings, prices, or launch dates.
- Sample interaction data must be identified as demo data in source code.
